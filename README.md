# Iran Reports

Workspace for Iran-related report notes, source material summaries, and supporting scripts.

## Structure

- `reports/` - final or draft report text.
- `notes/` - working notes and research logs.
- `scripts/` - helper scripts for processing text data.

## File Policy

This repository is configured to track program source, scripts, text, and common text-based configuration files. Binary assets such as PDFs, images, office documents, archives, audio, and video files are ignored by default.
