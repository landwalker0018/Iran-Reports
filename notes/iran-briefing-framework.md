# 伊朗局势简报制作框架

版本：2026-05-30
用途：支持在任意制作时点，向前回溯指定时间窗，生成伊朗局势简报、快报或专题复盘。

## 1. 任务定义

每次制作先固定四个参数：

- `T0`：简报锚点时间，默认使用北京时间 `Asia/Shanghai`。
- `L`：回溯窗口，可选 `6h / 12h / 24h / 48h / 72h / 7d / 自定义`。
- `Scope`：主题范围，可选 `综合局势 / 军事冲突 / 核谈判 / 霍尔木兹 / 能源市场 / 制裁经济 / 国内稳定`。
- `Audience`：读者对象，可选 `决策简报 / 研究笔记 / 舆情监测 / 交易前观察`。

信息窗口写法：

```text
信息窗口：{{T0-L}} -> {{T0}} CST
对应纽约时间：{{T0-L_NY}} -> {{T0_NY}} ET
回溯长度：{{L}}
冲突天数：第 {{N}} 天（如沿用 2026-02-28 为起点）
```

## 2. 生产流程

1. 设定参数：确认 `T0 / L / Scope / Audience`。
2. 拉取消息：按来源层级检索窗口内信息，同时补查窗口前 24 小时的背景事件，避免漏掉延迟报道。
3. 去重归并：同一事件按“最早发生时间、最早报道源、后续确认源”合并。
4. 事实分级：给每条事件标注可信度、影响方向和影响强度。
5. 建立时间线：按发生时间倒序排列，无法确认发生时间时按发布时间排列并注明。
6. 计算烈度：使用统一指标评分，并和上一窗口比较。
7. 输出判断：给出核心结论、情景推演、观察指标和证据表。
8. 质量检查：检查时间、来源、占位符、评分依据、未证实信息标记。

## 3. 消息源体系

### A 层：权威确认源

用于确认事实是否成立，优先引用。

- 中国官方/央媒：央视新闻、央视网、新华网、新华社通稿。
- 伊朗官方：IRNA、伊朗外交部、伊朗最高领袖办公室、伊朗总统府、伊朗军方/革命卫队声明。
- 美国/以色列/联合国官方：白宫、美国国务院、美国国防部、以色列总理府、以色列国防军、联合国安理会、IAEA。
- 交易和市场官方数据：ICE Brent、EIA、OPEC、主要交易所或数据商。

### B 层：专业通讯社和国际媒体

用于补充速度、现场细节和交叉验证。

- Reuters、AP、AFP、Bloomberg、Financial Times、Wall Street Journal。
- Al Jazeera、Times of Israel、Haaretz、The National、Middle East Eye。
- 中国商业/观察类媒体：财新、华尔街见闻、观察者网等，适合作为中文线索源，但关键事实仍需回到 A/B 层复核。

### C 层：区域和立场源

用于理解各方叙事、政策口径和舆论方向，必须标明立场。

- 伊朗半官方/派系媒体：Tasnim、Fars、Mehr、Press TV。
- 海湾和中东媒体：Asharq Al-Awsat、Al Arabiya、Gulf News、TRT World。
- 以色列本地媒体：Ynet、Jerusalem Post、Kan。

### D 层：数据、OSINT 与市场情绪

用于辅助判断，不单独作为重大事实确认依据。

- 航运：MarineTraffic、VesselFinder、TankerTrackers、Lloyd's List。
- 航空：FlightRadar24、ADS-B Exchange。
- 能源：Brent/WTI、天然气、油轮运价、保险费率、炼厂和港口数据。
- 预测市场：Polymarket 相关伊朗、停火、霍尔木兹和油价合约。
- 社交平台：X/Telegram/当地视频源，只作为线索，需做地理定位、时间验证和多源确认。

## 4. 可信度标记

每条事件必须带可信度：

- `A`：官方声明或至少两个高可信独立来源互证。
- `B`：一个高可信来源报道，且与已知事实链一致。
- `C`：区域/立场源或单一匿名源，尚缺独立确认。
- `D`：社交媒体、公开视频、传言或市场传闻，只能列入“待核实”。

重大判断规则：

- 涉及开战、停火、领袖伤亡、核设施、霍尔木兹关闭、能源设施受袭，至少需要 `A` 或两个 `B` 级来源。
- 若只能达到 `C/D`，不得写成既成事实，只能表述为“有报道称 / 尚待确认 / 市场正在定价”。

## 5. 事件卡片格式

```text
① {{事件标题}}
时间：{{CST 精确到分钟或秒}}（{{ET 不带年份}}）
地点：{{国家/城市/设施/海域}}
事实：{{一句话说明发生了什么}}
证据：{{来源 1}}；{{来源 2}}
可信度：{{A/B/C/D}}
影响：{{军事/外交/能源/制裁/国内/市场}}，{{升温/降温/中性}}
简评：{{为什么重要，不超过 2 句}}
```

排序规则：

- 默认按发生时间倒序。
- 发生时间不明时按发布时间倒序，并注明“发生时间未明”。
- 同一事件持续更新时合并为一张卡，保留最新进展和最早来源。

## 6. 分析框架

### 6.1 烈度指数

总分 100 分。每项既看当前窗口内事件，也看相对上一窗口变化。

| 维度 | 权重 | 评分关注点 |
| --- | ---: | --- |
| 军事行动 | 20 | 打击规模、目标级别、伤亡、跨境范围、是否触及美以伊核心资产 |
| 战略升级信号 | 15 | 最高层威胁、核威慑表态、红线声明、动员令、军事部署 |
| 霍尔木兹与航运 | 15 | 通航限制、扣船/袭船、保险费率、AIS 异常、护航和封锁行动 |
| 核问题与外交谈判 | 15 | IAEA、核设施、铀浓缩、谈判进展、停火条件 |
| 能源市场 | 10 | Brent/WTI 价格、日内波动、油轮运价、天然气和成品油联动 |
| 制裁与经济战 | 8 | 新制裁、金融/航运/能源限制、豁免或执行力度变化 |
| 国内稳定与信息环境 | 7 | 互联网、抗议、物资、政府管控、官方动员 |
| 第三方斡旋与外溢风险 | 10 | 联合国、卡塔尔、土耳其、沙特、俄罗斯、中国、欧盟等介入效果 |

颜色：

- `🔴 80-100`：高烈度升级，存在区域战争、能源冲击或重大军事扩大风险。
- `🟠 60-79`：明显紧张，冲突/谈判/市场任一方向出现强信号。
- `🟡 40-59`：中等波动，有局部事件但尚未形成系统性升级。
- `🟢 0-39`：低烈度或缓和，主要为口头表态、技术性谈判或市场回落。

### 6.2 趋势判断

除总分外，必须给出方向：

```text
烈度：{{分数}} / 100，{{颜色}}
较上一窗口：{{+/- 分数}}，{{升温/降温/持平}}
主因：{{贡献最大的 2-3 个维度}}
```

### 6.3 三层分析

每个关键事件按三层写：

- 原始事实：谁在何时何地做了什么。
- 结构含义：它改变了哪条链路，如军事威慑、谈判筹码、航运风险、能源价格。
- 后续观察：接下来 6-24 小时应看什么信号。

## 7. 结论展示方式

### 7.1 首页摘要

```text

① {{判断 1}}
② {{判断 2}}

```

### 7.2 结论矩阵

| 结论 | 置信度 | 证据 | 影响 |
| --- | --- | --- | --- |
| {{结论 1}} | 高/中/低 | {{来源和事件}} | {{对军事/外交/市场的影响}} |
| {{结论 2}} | 高/中/低 | {{来源和事件}} | {{对军事/外交/市场的影响}} |

### 7.3 情景推演

每份简报给出 3 个情景，适合决策阅读：

| 情景 | 概率 | 触发条件 | 观察指标 |
| --- | ---: | --- | --- |
| 升级 | {{%}} | {{例如新一轮打击/封锁升级}} | {{军方声明、航运异常、油价跳升}} |
| 僵持 | {{%}} | {{双方维持低频对抗}} | {{外交表态、局部袭击、市场震荡}} |
| 缓和 | {{%}} | {{停火延长/谈判恢复}} | {{斡旋声明、通航恢复、风险溢价回落}} |

概率不够时可不用百分比，改用 `高 / 中 / 低`，但必须说明依据。

### 7.4 风险雷达

```text
军事：高/中/低
外交：高/中/低
航运：高/中/低
能源：高/中/低
制裁：高/中/低
国内稳定：高/中/低
```

每项只写一个理由，避免堆砌。

## 9. 质量检查清单

- 是否明确 `T0`、`L`、时区和信息窗口。
- 是否所有数字都来自真实数据或明确说明缺口。
- 是否每条关键事件都有来源和可信度。
- 是否区分“发生时间”和“发布时间”。
- 是否将传闻、匿名消息、市场定价与已确认事实分开。
- 是否给出烈度分数、变化方向和评分依据。
- 是否有结论矩阵、情景推演和待核实清单。
- 是否避免空泛判断，如“局势复杂”“仍需观察”，除非后面接具体观察指标。

## 10. 相比原 SOP 的主要改进

- 从固定每日 24 小时，改为 `T0 + L` 的任意时点回溯机制。
- 从单一来源列表，改为分层来源体系和可信度标记。
- 从事件罗列，改为“事件卡片 + 烈度指数 + 结论矩阵 + 情景推演”。
- 从静态总分，改为总分、变化方向和主因解释。
- 从结尾三句判断，改为一句话结论、三条核心判断、风险雷达和观察指标。
